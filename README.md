## SR Pro — Next.js

Converted from the Vite + React Minimal dashboard to **Next.js App Router**.

### Prerequisites

- Node.js 20.x (Recommended)

### Installation

```sh
npm install --legacy-peer-deps
npm run dev
```

App runs at [http://localhost:3000](http://localhost:3000). The home route redirects to `/dashboard`.

Demo API (optional): set `NEXT_PUBLIC_SERVER_URL` in `.env`.
